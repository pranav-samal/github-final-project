# Simple Interest Calculator

This repository contains a simple interest calculator project.

## Project Name
**Simple Interest Calculator**

## Description
A calculator application that computes simple interest based on user input.
It takes the following inputs:
- **Principal** – the initial amount of money
- **Rate of Interest** – the annual interest rate (%)
- **Time Period** – the duration in years

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Usage
Run the `simple-interest.sh` script to calculate simple interest interactively via the command line.
